# ATP — Clase 01: Checklist previo

Duración: 180 minutos.
Especialidades: electricidad residencial, industrial y electromecánica.

## 1. Logística con ATP

- [ ] Fecha y hora confirmadas.
- [ ] Cantidad de estudiantes confirmada.
- [ ] Salón disponible antes de comenzar.
- [ ] Responsable de ATP identificado.
- [ ] Pantalla y conexión verificadas.
- [ ] Pizarra y marcadores disponibles.

## 2. Equipos de protección personal

- [ ] Cascos de seguridad.
- [ ] Gafas de protección.
- [ ] Guantes de distintos tipos.
- [ ] Calzado de seguridad.
- [ ] Chalecos reflectivos.
- [ ] Vestimenta apropiada para demostraciones.
- [ ] Etiquetas e instrucciones disponibles.
- [ ] Equipos inspeccionados antes de utilizarlos.

## 3. Escaleras y arneses

- [ ] Escalera inspeccionada y estable.
- [ ] Espacio despejado para posicionarla.
- [ ] Arnés de cuerpo completo disponible.
- [ ] Etiquetas y manual del arnés revisados.
- [ ] Equipo deteriorado retirado de uso.
- [ ] Sin actividades de ascenso o suspensión.

## 4. Señalización

- [ ] Conos disponibles.
- [ ] Cintas de advertencia.
- [ ] Señales de seguridad.
- [ ] Soportes para delimitar el área.
- [ ] Rutas de evacuación despejadas.

## 5. Kit LOTO

- [ ] Candados y etiquetas disponibles.
- [ ] Dispositivos de bloqueo identificados.
- [ ] Modelo didáctico completamente inerte.
- [ ] Fuentes de energía peligrosa ausentes.
- [ ] Demostración previamente ensayada.

## 6. Materiales del instructor

- [ ] Presentación HTML revisada.
- [ ] Copia local de respaldo.
- [ ] Guion rápido disponible.
- [ ] Guía técnica disponible.
- [ ] Actividades prácticas revisadas.
- [ ] Preguntas del cierre preparadas.
- [ ] Referencias normativas verificadas.
- [ ] Reloj o cronómetro disponible.

## 7. Seguridad del laboratorio

- [ ] Máquinas fuera de las demostraciones.
- [ ] Equipos sin energía peligrosa.
- [ ] Suelo y áreas de circulación despejados.
- [ ] Salidas de emergencia identificadas.
- [ ] Procedimiento de emergencias conocido.
- [ ] Botiquín identificado.
- [ ] Criterio para detener una práctica definido.

## 8. Antes de iniciar

- [ ] Materiales distribuidos por actividad.
- [ ] Proyección funcionando.
- [ ] Cronograma de 180 minutos disponible.
- [ ] Demostraciones verificadas.
- [ ] Espacio seguro para estudiantes.
